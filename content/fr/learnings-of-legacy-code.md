L'architecture logicielle ne dépend pas du code moderne. Elle s'applique à toute base de code, même legacy. J'ai lu cela dans un livre une fois, mais ce travail m'a forcé à mettre cette connaissance en pratique.

![Diagramme de Clean Architecture montrant la séparation des responsabilités en ASP.NET](https://web.archive.org/web/20251210155229/https://blog.ndepend.com/wp-content/uploads/Clean-Architecture-Diagram-Asp-Net.png)

La partie difficile, ce ne sont pas les patterns — c'est traduire la compétence technique en résolution réelle de problèmes. Il faut communiquer, s'aligner avec l'équipe et pousser vers des objectifs partagés.

![Les compétences humaines sont essentielles pour les développeurs travaillant avec des systèmes legacy](https://www.husson.edu/online/blog/2024/09/soft-skills-blog-image.jpg)

Le code seul ne livre pas les features. Les gens, si.

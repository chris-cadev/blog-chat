I'm thinking about going back to Linux. The main reason is simple: almost all
the AI tools I use right now run Linux commands.

## AI tools prefer Linux

The AI tools I'm using throw Linux commands naturally. On Windows you have to
teach them the equivalent, or rewrite everything afterward.

There's also more documentation on how to program with Linux: tutorials, issues,
the conversation on forums.

I don't know the Windows communities well enough to be sure there isn't
something better over there. Day to day, the pattern leans Linux.

## I barely play anymore

Another reason: I barely play at all. What I do play are cooperative games with
friends, not competitive ones.

My go-to game is Minecraft. It runs on any machine with Java installed. I don't
play Bedrock, so the move doesn't get complicated there.

If gaming was the anchor on Windows, it almost isn't anymore.

## ShareX and what I want to keep

There are Windows things I'd like to keep. The most concrete one is ShareX: I
didn't find an equivalent tool, in terms of features, on Linux. I'll have to
look for alternatives.

If I have to inventory the software and swap tools, that deserves its own
log: how I'm moving, what replaces what, and what stays.

## It's still an idea

For now it's an idea. I'm still working on it.
